# 参考资料怎么用

资料按当前课程选读，不要求先看完再动手。讲义应链接具体相关章节，并解释阅读目的。

| 资料 | 用途 |
| --- | --- |
| [Python 3.12 教程](https://docs.python.org/3.12/tutorial/) | 补充函数、列表、模块、异常和文件操作等必要语法 |
| [uv 项目指南](https://docs.astral.sh/uv/guides/projects/) | 解释项目环境、依赖声明、锁文件和运行命令 |
| [PyTorch Basics](https://docs.pytorch.org/tutorials/beginner/basics/intro.html) | 张量、自动求导、训练循环和模型保存的官方入门 |
| [动手学深度学习](https://zh.d2l.ai/) | 结合可运行例子补齐线性代数、概率、优化和神经网络 |
| [Neural Networks: Zero to Hero](https://karpathy.ai/zero-to-hero.html) | 从梯度与字符模型走向 GPT，作为实现与讲解参照 |
| [Stanford CS336: Language Modeling from Scratch](https://stanford-cs336.github.io/) | 在具备基础后深入分词、Transformer、训练系统与数据处理 |
| [Attention Is All You Need](https://arxiv.org/abs/1706.03762) | 阅读注意力和 Transformer 的原始设计；注意原论文含 encoder 与 decoder，和本课 decoder-only 模型有区别 |
| [Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1) | 在自制小模型之后学习预训练模型、分词与微调生态 |

模型 API、检索和工具调用的参考资料在实际选定组件时加入，随课程使用版本核对。
