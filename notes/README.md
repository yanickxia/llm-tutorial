# 学习记录

笔记按学习阶段分组，文件名沿用全局课号 `note-NN.md`。

教程在 `docs/lesson-NN.md`，负责原理、例子、实验步骤与题目；这里负责保存你的预测、答案与实验记录。
每篇笔记链接到对应教程，按“读教程 → 在笔记里预测 → 做实验并补全记录 → 导师审阅”的顺序推进。

| 已开放阶段 | 课程 | 目录 |
| --- | --- | --- |
| 01 · 基础与实验环境 | 第 0 课 | [01-基础与实验环境](01-基础与实验环境/) |

后续阶段在实际开课时建立目录并更新此表。规划见 [路线图](../docs/roadmap.md)。

学习者填写预测、观察与解释，导师在独立栏目中审阅。原预测不要擦掉；修订时记录新证据。
生成笔记骨架不代表学习者已作答，导师跑通脚手架也不代表已经结课。

写好当前笔记后，在聊天中说“review 第 N 课笔记”即可，导师直接读取文件、相关实现与实验记录。
有问题时在“导师审阅”指出具体缺口，你在笔记中补充后再审；审阅通过后，导师记录结课、更新路线图，
并直接准备下一课的教程、空白笔记和实验脚手架。

新课笔记从 [模板](../docs/templates/note.md) 开始。
